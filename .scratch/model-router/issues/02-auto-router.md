# Chunk 2 — эвристический авто-роутер

## Цель

Автоматически выбирать лёгкую или тяжёлую модель по тексту сообщения, с возможностью ручного переопределения.

## Шаги

1. `daneel/router.py`: `ModelRouter.choose(text)`.
2. Правила: инструменты → тяжёлая; длинный текст/код/сложные слова → тяжёлая; иначе лёгкая.
3. В `send()` применять роутер, если включён `auto_route`; `/model` переключает в manual, `/router auto` возвращает.
4. Табличные тесты правил и TUI-тест смены модели после сложного сообщения.

## Критерии готовности

- «Привет» уходит на `qwen2.5:1.5b`.
- Вопрос про погоду/файлы уходит на `qwen3.5:4b`.
- `/model` отключает авто-выбор до `/router auto`.
