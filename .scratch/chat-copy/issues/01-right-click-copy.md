# 01: Копирование выделенного фрагмента правым кликом

**Что делаем:** Пользователь выделяет мышью любой текст в ленте сообщений и нажимает правую кнопку — выделенный фрагмент оказывается в системном буфере, а в чате появляется локализованная заметка об успехе. Если выделения нет, показывается отдельная заметка и ничего не копируется. Поведение проверяется через механизм приложения без реального терминала.

**Блокируется:** None (can start immediately)

Status: ready-for-agent

- [ ] Правый клик с выделением копирует выделенный текст в буфер приложения.
- [ ] Отсутствие выделения ничего не копирует и показывает локализованную заметку.
- [ ] Заметка об успехе локализована на обоих языках интерфейса.
- [ ] Тест управляет приложением через штатный механизм и проверяет результат через локальный буфер.
- [ ] Полный набор тестов проходит.
