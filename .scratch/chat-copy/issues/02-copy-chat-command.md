# 02: Команда копирования чата

**Что делаем:** Пользователь вводит `/copy`, чтобы скопировать весь видимый транскрипт чата, или `/copy last`, чтобы скопировать только последний ответ агента. В транскрипт входят сообщения пользователя и агента, ошибки и системные заметки в том виде, как они показаны, но не приветственный баннер. `/clear` очищает источник копирования, поэтому команда никогда не возвращает устаревший текст. Справка и все заметки локализованы.

**Блокируется:** None (can start immediately)

Status: ready-for-agent

- [ ] `/copy` помещает в буфер весь видимый транскрипт в порядке отображения.
- [ ] `/copy last` помещает в буфер только последний ответ агента.
- [ ] Пустой чат даёт локализованную заметку вместо пустой операции.
- [ ] `/clear` очищает транскрипт, после чего копировать нечего.
