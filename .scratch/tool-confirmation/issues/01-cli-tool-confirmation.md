# 01: Подтверждение инструментов в текстовом режиме

**What to build:** Пользователь текстового режима видит перед каждым вызовом инструмента локализованный запрос с именем инструмента и его аргументами. Enter или утвердительный ответ разрешает вызов, явный отказ запрещает его, и отказ отображается как ошибка. Логика запроса проверяется автоматически без интерактивного терминала, а пользовательский колбэк, переданный в разговор извне, не перетирается.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] В текстовом режиме перед вызовом инструмента выводится запрос с именем инструмента и аргументами на языке интерфейса.
- [ ] Enter и утвердительные ответы на обоих поддерживаемых языках разрешают вызов.
- [ ] Явный отказ запрещает вызов, инструмент не выполняется, пользователь видит сообщение об отказе.
- [ ] Решение о подтверждении тестируется через внедрённые потоки ввода и вывода.
- [ ] Внешне заданный колбэк подтверждения сохраняет приоритет над интерфейсным.
- [ ] Полный набор тестов проходит.
