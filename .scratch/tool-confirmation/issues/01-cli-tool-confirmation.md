# 01: Подтверждение инструментов в текстовом режиме

**What to build:** Пользователь текстового режима видит перед каждым вызовом инструмента локализованный запрос с именем инструмента и его аргументами. Enter или утвердительный ответ разрешает вызов, явный отказ запрещает его, и отказ отображается как ошибка. Логика запроса проверяется автоматически без интерактивного терминала, а пользовательский колбэк, переданный в разговор извне, не перетирается.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] В текстовом режиме перед вызовом инструмента выводится запрос с именем инструмента и аргументами на языке интерфейса.
- [x] Enter и утвердительные ответы на обоих поддерживаемых языках разрешают вызов.
- [x] Явный отказ запрещает вызов, инструмент не выполняется, пользователь видит сообщение об отказе.
- [x] Решение о подтверждении тестируется через внедрённые потоки ввода и вывода.
- [x] Внешне заданный колбэк подтверждения сохраняет приоритет над интерфейсным.
- [x] Полный набор тестов проходит.
