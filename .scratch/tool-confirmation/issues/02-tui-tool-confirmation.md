# 02: Подтверждение инструментов в терминальном интерфейсе

**What to build:** Пользователь терминального интерфейса видит модальное окно с именем инструмента и его аргументами, когда агент запрашивает вызов. Кнопки Allow и Deny переключаются с клавиатуры; Enter подтверждает выбранную кнопку, Esc и клавиша отказа запрещают вызов. Все строки окна локализованы. Поведение проверяется через существующий механизм тестирования приложения с синтетическими нажатиями клавиш.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] При вызове инструмента открывается модальное окно с именем инструмента и аргументами.
- [ ] Enter подтверждает выбранную кнопку, начальный выбор — Allow.
- [ ] Esc и клавиша отказа запрещают вызов без выполнения инструмента.
- [ ] Заголовок, кнопки и сообщения отображаются на обоих поддерживаемых языках интерфейса.
- [ ] Разрешение и запрет проверяются через синтетические нажатия клавиш; выполнение инструмента наблюдается в тесте.
- [ ] Полный набор тестов проходит.
