# 02: Подтверждение инструментов в терминальном интерфейсе

**What to build:** Пользователь терминального интерфейса видит модальное окно с именем инструмента и его аргументами, когда агент запрашивает вызов. Кнопки Allow и Deny переключаются с клавиатуры; Enter подтверждает выбранную кнопку, Esc и клавиша отказа запрещают вызов. Все строки окна локализованы. Поведение проверяется через существующий механизм тестирования приложения с синтетическими нажатиями клавиш.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] При вызове инструмента открывается модальное окно с именем инструмента и аргументами.
- [x] Enter подтверждает выбранную кнопку, начальный выбор — Allow.
- [x] Esc и клавиша отказа запрещают вызов без выполнения инструмента.
- [x] Заголовок, кнопки и сообщения отображаются на обоих поддерживаемых языках интерфейса.
- [x] Разрешение и запрет проверяются через синтетические нажатия клавиш; выполнение инструмента наблюдается в тесте.
- [x] Полный набор тестов проходит.
