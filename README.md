# Daneel.AI 🤖

**Daneel.AI** (Р. Даниел Оливо) — это локальный автономный ИИ-агент с открытой архитектурой. Проект ориентирован на абсолютную приватность, работу в офлайн-режиме (on-premise) и постепенное расширение под домашние и корпоративные задачи.

## 🎯 Цель MVP
Создать минимальный рабочий протокол общения "Пользователь ⇄ Агент ⇄ Локальная LLM" на чистом Python с возможностью дальнейшего превращения в мультиагентную систему.

## 🛠️ Стек технологий
* **Язык:** Python 3.10+
* **Среда запуска моделей:** [Ollama](https://ollama.com)
* **Базовая модель:** `qwen2.5:1.5b` (быстрая, легковесная, для тестов) или `llama3.2:3b`

## 🚀 Быстрый старт

1. Установите и запустите Ollama. Скачайте модель в терминале:
   ```bash
   ollama run qwen2.5:1.5b
   ```
2. Клонируйте проект и установите зависимости:
   ```bash
   pip install requests
   ```
3. Запустите агента:
   ```bash
   python main.py
   ```
